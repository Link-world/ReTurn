# Project page assets

Figures and aggregate scores used by the [ReTurn project page](../index.html).

- `four_conditions.png`: the four benchmark conditions.
- `construction.png`: benchmark construction and paired evaluation.
- `leaderboard.png` / `.svg` / `.csv`: full-benchmark model results.
- `history_ladders.png` / `.svg` / `.csv`: paired-condition summaries.
- `history_cases.png`: illustrative task-side and evidence-side cases.

Figures are paper illustrations, not the downloadable evaluation media. Third-party content retains its original rights; see [media notices](../../THIRD_PARTY_MEDIA.md). No paper PDF or raw evaluation media are included here.
